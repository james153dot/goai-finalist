the committed numerical evidence predates later naming/interpretation cleanup
instead of silently rewriting that history.

## Numerical artifacts are preserved

This compliance pass does **not** alter the numerical OpenFOAM evaluations,

## `Cconv` versus `Cvalid`

Some committed historical JSONL rows use `Cconv`. Current code uses `Cvalid`
for the narrower statement actually supported by the wrapper: the OpenFOAM
run completed, required fields were available, and derived metrics were
finite.

`Cvalid` is **not** an independently parsed residual-convergence certificate.
For backward compatibility, readers use the effective rule:

```python
row.get("Cvalid", row.get("Cconv", False))
```

Therefore an older row containing only `Cconv` remains readable without
pretending that its original file was generated by the latest schema.

## Hypothesis interpretation revision

Early campaign metadata used the label `falsified` for the swirl-monotonicity
hypothesis when sparse 5-D neighboring observations crossed the analog
stability boundary. Because those comparisons also vary other design
coordinates, they do not isolate a one-factor causal effect of swirl.

Current source code therefore uses the more defensible interpretation:

- sparse multivariate evidence may **challenge** a global monotonicity claim;
- it does **not** by itself constitute a controlled causal falsification;
- the fixed-family swirl sweep is the controlled follow-up;
- unstable samples surrounded by stable neighbors may motivate a topology
  follow-up, but do not prove a disconnected 5-D component.

Some committed `campaign.json` or comparison metadata may retain the legacy
wording because it is part of the historical generated artifact. When legacy
metadata and current source wording differ, this document and current source
state the intended interpretation. The underlying numerical evidence is
unchanged.

## Reproducing final-source metadata

Fresh campaigns generated with the patched source write `schema_version = 2`
and an explicit `interpretation_policy` block in `campaign.json`.

A full live-CFD regeneration is intentionally **not** performed merely to
change prose/status labels. If numerical artifacts are regenerated later, the
new commit SHA, OpenFOAM version, seed, budget, iteration cap, and output path
should be recorded in this file or the manifest.
